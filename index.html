About The Project

The Smart Blind Stick is designed to assist visually impaired users by detecting obstacles and providing useful location information. The system combines ultrasonic sensors, a GPS module, ESP8266 Wi-Fi and ESP32-CAM technology to create a modern assistive solution.

Demo: This website is currently a presentation dashboard. Hardware data is not connected to the website yet.

System Features

Main technologies used in the project

◉

Ultrasonic Sensor

Detects obstacles in front of the user and helps provide safer navigation.

⌖

GPS Tracking

The GPS module can determine the geographical location of the Smart Blind Stick.

◌

ESP8266 Wi-Fi

Provides wireless connectivity so information can be transferred to an online system.

▣

ESP32-CAM

Provides camera functionality for visual monitoring and future smart features.
